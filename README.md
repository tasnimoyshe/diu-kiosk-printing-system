\# DIU Kiosk Printing and Sales Management System



A full-stack Printing and Sales Management System built for a university kiosk environment.



The system manages:



\- public print requests

\- multiple document uploads

\- printing price calculation

\- cash payment verification

\- paid/unpaid queue priority

\- request processing

\- agent management

\- inventory sales

\- administrator reporting

\- agent performance

\- real-time updates
